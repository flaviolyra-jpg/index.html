Passo a Passo Oficial para o Aluno (Flávio)

Como colocar e manter seu portfólio no ar de forma 100% gratuita.

1 Criar o Banco no Firebase Console

Acesse console.firebase.google.com, crie um projeto chamado portfolio-flavio-ifrn.

2 Ativar Firestore & Regras de Segurança

Em Build > Firestore Database, crie o banco de dados. Configure as Regras de Segurança para:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

3 Criar Conta de Administrador

Em Build > Authentication, ative E-mail/Senha e adicione seu usuário (ex: flavio.augusto@ifrn.edu.br).

4 Publicar o Link do Portfólio

Suba este único arquivo index.html no GitHub Pages ou Vercel. Envie o link para o Prof. Elialdo Chibério!
